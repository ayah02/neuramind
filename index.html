Architecture

Dual-stream ensemble design

Two parallel branches merge, then combine with LightGBM through weighted averaging.

Stream 1: Keras Neural Network

Two parallel branches — one per data type. Each: Swish activations, BatchNorm, Dropout:

Dense(256, 'swish') → BatchNorm()
→ Dropout(0.3) → Dense(128, 'swish')
Concat → Dense(128) → Dense(1, sigmoid)
SwishBatchNormDropout 0.3Adam

Stream 2: LightGBM + PCA

fMRI connectome matrices (36P Pearson) reduced with PCA (99% variance). Sex model applies SelectFromModel feature filtering:

fMRI → PCA(n_components=0.99)
Sex only: SelectFromModel(
LGBMClassifier(500),
threshold="median")
→ LGBMClassifier(n_estimators=500)
PCA 99%36P PearsonSelectFromModel

Ensemble Fusion

Different weights per task — tuned because ADHD and sex prediction have different signal characteristics:

ADHD: 0.4×keras + 0.6×lgbm
Sex: 0.5×keras + 0.5×lgbm
ADHD loss: binary_crossentropy
Sex loss: focal_loss(γ=2, α=0.25)
threshold → maximise F1
ADHD: 40/60Sex: 50/50Focal Loss

Training & Results

StratifiedKFold (k=5). F1-maximising threshold sweep. All metrics from printed notebook output:

ADHD: TN=193 FP=189 FN=49 TP=782
→ Recall 94.1% F1 86.8% AUC 0.82
Sex: TN=543 FP=254 FN=90 TP=326
→ Recall 78.4% AUC 0.81
Combined CV accuracy: 78.03%
5-Fold CVseed=42epochs=60
Pipeline

From raw data to prediction

1
Merge TRAIN_QUANTITATIVE_METADATA, TRAIN_CATEGORICAL_METADATA, TRAINING_SOLUTIONS, fMRI 36P-Pearson connectome matrices on participant_id — 1,213 rows, ADHD+: 831, ADHD−: 382
2
Numerical: SimpleImputer(median) + StandardScaler. Categorical: mode + OneHotEncoder(handle_unknown='ignore'). Connectome: median + StandardScaler + PCA(0.99)
3
Sex model only: SelectFromModel(LGBMClassifier(500), threshold="median") on PCA-reduced connectome — keeps above-median importance features
4
Train dual-branch Keras + LGBMClassifier(500) inside 5-fold StratifiedKFold (shuffle=True, random_state=42), 60 epochs, batch_size=128
5
Find F1-optimal threshold: for t in np.arange(0.1, 0.9, 0.01): score = f1_score(y_val, preds>t) → keep best t
6
This website replicates steps 4–6 in JavaScript — your answers feed the same dual-stream ensemble logic with weights keras=0.4, lgbm=0.6 and threshold=0.53
